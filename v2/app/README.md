# App Controle Financeiro (Flutter)

Veja as instruções em [../README.md](../README.md).

```
lib/
├── main.dart          # inicialização, tema, login x app
├── core/              # config (API_URL), cliente HTTP, formatação, tema
├── models/            # modelos que espelham a API
├── services/          # FinanceApi: todas as chamadas ao backend
├── state/             # AuthController e DataVersion (recarregar telas)
├── widgets/           # componentes e gráficos
└── screens/           # telas
```
